# Публикация VELMONT бесплатно: GitHub + Supabase + Render

Результат: сайт по адресу `https://что-то.onrender.com`, админка по `/admin/`, заказы идут в Telegram, товары и фото не пропадают.
Всё делается в браузере, около 20–30 минут. Сначала запомните: **файл `.env` на GitHub загружать нельзя** (там пароль и токен бота).

## Шаг 1. GitHub: загрузить папку с сайтом
1. Зарегистрируйтесь на https://github.com.
2. Справа вверху «+» → «New repository». Имя: `velmont`. Выберите **Private**. Нажмите «Create repository».
3. **Перед загрузкой** вынесите файл `.env` из папки `velmont-store` в другое место (например, на рабочий стол). Папку `storage` тоже не загружайте.
4. В новом репозитории нажмите «uploading an existing file». Откройте папку `velmont-store` и перетащите в окно **всё её содержимое** (файлы `server.js`, `package.json`, папку `public` и остальное), а не саму папку.
5. Нажмите «Commit changes».

## Шаг 2. Supabase: база данных и хранилище фото
1. Зарегистрируйтесь на https://supabase.com, нажмите «New project». Имя `velmont`, придумайте пароль базы (запишите), регион выберите ближайший (например, Frankfurt). Подождите 1–2 минуты, пока проект создастся.
2. В левом меню откройте «SQL Editor» → «New query». Откройте файл `supabase-setup.sql` из папки сайта, скопируйте всё содержимое, вставьте и нажмите «Run». Должно появиться «Success».
3. Откройте «Project Settings» (шестерёнка) → «API» (раздел может называться «API Keys»). Скопируйте:
   - **Project URL**, например `https://abcdxyz.supabase.co`;
   - **service_role** ключ (секретный, на вкладке «Legacy API keys»). Если такой вкладки нет, возьмите ключ «secret» (начинается с `sb_secret_`).
4. Секретный ключ никому не показывайте и не вставляйте в GitHub. Он вписывается только на Render (шаг 3).

## Шаг 3. Render: запустить сайт
1. Зарегистрируйтесь на https://render.com через кнопку «GitHub».
2. «New +» → «Web Service» → выберите репозиторий `velmont` (разрешите Render доступ к нему).
3. Настройки:
   - Language / Runtime: **Node**
   - Build Command: `echo ok`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. Ниже в «Environment Variables» добавьте (кнопка «Add Environment Variable»):

   | Имя | Значение |
   |---|---|
   | `ADMIN_USER` | `admin` |
   | `ADMIN_PASSWORD` | ваш длинный пароль для админки |
   | `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
   | `TELEGRAM_CHAT_ID` | `@velmont_shop` (или число; несколько через запятую) |
   | `SUPABASE_URL` | Project URL из шага 2 |
   | `SUPABASE_SERVICE_KEY` | секретный ключ из шага 2 |

5. Нажмите «Create Web Service». Через 2–4 минуты вверху появится адрес вида `https://velmont-xxxx.onrender.com`.
6. Откройте его: сайт должен загрузиться. Админка: тот же адрес + `/admin/`. В «Настройки» нажмите «Отправить тестовое сообщение», чтобы проверить Telegram.

В журнале Render («Logs») при успешном старте будет строка «Хранилище: Supabase».

## Шаг 4. Чтобы сайт не засыпал (бесплатно)
На бесплатном тарифе Render усыпляет сайт после 15 минут без посетителей, и первое открытие занимает около минуты.
1. Сайт уже **сам пингует себя** каждые 10 минут (работает на Render автоматически, отключается переменной `KEEP_ALIVE=0`).
2. Для надёжности добавьте и внешний пинг: на https://uptimerobot.com «Add New Monitor» → HTTP(s), URL `https://velmontstyle.uz/healthz`, интервал 5 минут. Он же пришлёт сообщение, если сайт упадёт.
3. Платный тариф Starter в Render не засыпает вообще. Это самый надёжный вариант.

## Обновление сайта позже
Загрузите изменённые файлы в репозиторий GitHub (кнопка «Add file» → «Upload files»). Render сам обновит сайт. Товары, заказы и фото остаются в Supabase, их обновление не затронет.

## Если что-то не работает
- **В логах «Не удалось подключиться к Supabase»**: проверьте `SUPABASE_URL` (без пробелов, начинается с `https://`) и ключ; убедитесь, что SQL из шага 2 выполнен.
- **Фото не загружаются**: в Supabase → Storage должен быть бакет `uploads` (создаётся тем же SQL). Размер видео ограничен 50 МБ.
- **Telegram не отвечает**: см. README, раздел «Заказы в Telegram». Для канала бот должен быть его администратором.
- **Админка просит пароль, а он не подходит**: проверьте `ADMIN_PASSWORD` в Render → Environment и нажмите «Save, rebuild and deploy».
- Резервную копию делайте время от времени: админка → Настройки → «Скачать копию».

## Подтверждение номера, карта и статусы заказов

- **Номер подтверждается через Telegram-бота.** Отдельных настроек нет: проверка включается сама, когда на Render задан `TELEGRAM_BOT_TOKEN`. Покупатель нажимает «Подтвердить через Telegram», в боте жмёт Start и «Поделиться номером». Бот принимает только контакт самого пользователя.
- **Один токен бота нельзя запускать в двух местах одновременно.** Если сайт работает на Render, не запускайте `start.bat` на компьютере с тем же токеном: они будут мешать друг другу. Для проверки дома создайте второго бота у @BotFather.
- **Адрес выбирается на карте OpenStreetMap** (бесплатно, ключи не нужны). Без точки на карте заказ не оформится. Доставка принимается только по Узбекистану.
- **Статусы заказа.** В админке в карточке заказа кнопки «Передан в доставку» и «Доставлен», а также поле «№ отправления BTS». Покупатель видит статус в «Мои заказы», страница обновляется сама.
- Бесплатный Render «засыпает» без посетителей, и в это время бот не отвечает. Настройте UptimeRobot (шаг 4 выше), тогда сайт и проверка номера работают без задержек.

## Cloudflare перед сайтом (быстрее и стабильнее для части провайдеров)
1. Зарегистрируйтесь на https://cloudflare.com, «Add a site» → `velmontstyle.uz`, тариф Free.
2. В панели регистратора домена замените серверы имён (NS) на те, что покажет Cloudflare.
3. В Cloudflare → DNS: запись CNAME на `ваш-сайт.onrender.com`, оранжевое облако включено.
4. SSL/TLS → режим **Full**. Включите «Always Use HTTPS».
5. В Render → Environment добавьте `TRUST_CF=1`, чтобы ограничение частоты запросов видело настоящий IP посетителя.
Кэшировать нужно только картинки и стили. Страницы и `/api/*` Cloudflare не трогает, так как сервер сам отдаёт им заголовки «не кэшировать».

## Онлайн-оплата Payme и Click
Включается, только если заданы ключи (см. `.env.example`). Тогда в корзине появляется выбор «При получении / Payme / Click».
- **Payme:** в кабинете Paycom Business укажите Endpoint URL `https://velmontstyle.uz/api/pay/payme`, поле счёта `order_id`; `PAYME_KEY` берётся из кабинета (для тестов `PAYME_TEST=1`).
- **Click:** в кабинете Click Merchant укажите Prepare URL и Complete URL: `https://velmontstyle.uz/api/pay/click` (оба одинаковые), ключи — в переменные `CLICK_*`.
- Обязательно пройдите тестовую оплату в песочнице Payme / Click до запуска. Интеграция написана по их публичным описаниям и проверена на эмуляции запросов, но не на ваших реальных ключах.

## Резервная копия
В Supabase автоматические копии есть только на платном тарифе. Поэтому сервер сам раз в неделю присылает копию базы файлом в Telegram, если задан `BACKUP_CHAT_ID` (ваш личный чат с ботом: напишите боту, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `chat.id`). Не используйте для этого канал: в копии телефоны и адреса покупателей. Скачать копию вручную можно в админке (Настройки → Резервная копия).
