# VELMONT — магазин одежды

Сайт-магазин с админ-панелью и отправкой заказов в Telegram. Работает на Node.js без установки дополнительных пакетов.

## Быстрый старт (на своём компьютере)

**Самый простой способ:** установите Node.js (https://nodejs.org, версия 18 или новее), распакуйте архив и дважды щёлкните `start.bat` (Windows) или `start.command` (Mac). Сайт откроется сам. Окно с запущенным сервером не закрывайте.

**Вручную:**

1. Установите Node.js версии 18 или новее: https://nodejs.org
2. Файл `.env` уже создан: логин `admin`, пароль в `ADMIN_PASSWORD`. При желании измените их в блокноте.
3. В папке проекта выполните команду:

```
npm start
```

4. Откройте сайт: http://localhost:3000
5. Админ-панель: http://localhost:3000/admin/

На телефоне в той же Wi-Fi сети откройте `http://IP-вашего-компьютера:3000`.

## Админ-панель

Откройте `/admin/` и введите пароль. Всё работает и с телефона.

- **Товары.** Кнопка «+ Добавить товар»: название, каталог, цена, фото (можно несколько), размеры, цвет, описание. «Изменить» и «Удалить» есть у каждого товара. Изменения появляются на сайте сразу.
- **Каталоги.** Создавайте, переименовывайте, переставляйте и удаляйте разделы сайта.
- **Заказы.** Все заказы с именем, телефоном, составом и суммой. Можно отмечать выполненными.
- **Настройки.** Фоновая картинка сайта, тексты главной страницы, контакты, тест Telegram.

## Заказы в Telegram

1. В Telegram откройте @BotFather, отправьте `/newbot`, придумайте имя и получите токен.
2. Впишите токен в `.env`: `TELEGRAM_BOT_TOKEN=...`
3. Откройте своего бота в Telegram, нажмите Start и напишите «привет».
4. Выполните `npm run chatid`. Команда покажет ваш chat id.
5. Впишите его в `.env`: `TELEGRAM_CHAT_ID=...` (для нескольких получателей перечислите через запятую).
6. Перезапустите сервер. В админке, в «Настройки», нажмите «Отправить тестовое сообщение».

Токен хранится только на сервере и не попадает на сайт. Цены в заказе сервер пересчитывает сам, поэтому подменить их в браузере нельзя.

## Видео на главном экране

На главной за заголовком играет встроенное видео с шёлковыми волнами (`public/img/hero.webm` и `hero.mp4`). Свое видео: «Настройки» → «Видео на главном экране» → «Загрузить своё видео» → «Сохранить настройки». Формат MP4 или WebM, до 60 МБ, лучше 10–20 секунд без звука. На телефоне видео тоже играет, при включённом режиме «уменьшить движение» оно останавливается.

## Как сменить фон

«Настройки» → «Фон сайта» → «Загрузить фон» → «Сохранить настройки». Подойдёт горизонтальное тёмное фото одежды или бренда. Пока своего фото нет, показывается встроенная иллюстрация с вешалкой.

## Бесплатная публикация (GitHub + Supabase + Render)

Пошаговая инструкция лежит в файле `DEPLOY.md`. Для неё в проект добавлено хранение данных в Supabase.

## Публикация в интернете

Для админки и заказов нужен сервер, на котором работает Node.js: VPS (Timeweb, Hetzner, DigitalOcean и т. п.), Render или Railway.

- Загрузите проект, задайте переменные из `.env` в настройках хостинга, команда запуска `npm start`.
- **Важно:** товары и фото хранятся в папках `public/data` и `public/uploads`. На бесплатных хостингах диск может очищаться при каждом обновлении, поэтому подключите постоянный диск (Persistent Disk / Volume) к этим папкам или используйте VPS.
- Включите HTTPS (на VPS это Caddy или nginx с сертификатом, на Render и Railway он включён сам).
- **Netlify и GitHub Pages не подойдут** для админки и Telegram: они отдают только статические файлы. Сайт на них откроется, но каталог будет только для чтения. Заказ в таком случае откроет чат Telegram с готовым текстом (нужно указать Telegram в «Настройки → Контакты»).

## Что где лежит

```
server.js            сервер: сайт, админ API, загрузка фото, заказы
public/index.html    страница магазина
public/css/          стили сайта
public/js/app.js     каталог, карточка товара, корзина, анимации
public/js/art.js     силуэты вещей (показываются, пока нет фото)
public/admin/        админ-панель
public/data/         товары и настройки (JSON)
public/uploads/      загруженные фото
public/img/bg.svg    стандартный фон
storage/             заказы и ключ сессий (не публикуется)
```

## Безопасность

- Админ-панель закрыта паролем, вход ограничен по числу попыток.
- Не публикуйте файл `.env` и папку `storage/`. В `.env` лежат пароль и токен бота, никому не отправляйте этот файл и не выкладывайте его в интернет.
- Регулярно делайте копию папок `public/data`, `public/uploads` и `storage/`.
